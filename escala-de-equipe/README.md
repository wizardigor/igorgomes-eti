# Escala de Equipe

Aplicativo para montar escalas, variar a distribuição das folgas e exportar a grade em Excel/CSV ou o calendário em PDF. O PDF permite incluir a marca da empresa no cabeçalho e mantém a assinatura Igor Gomes ETI no rodapé.

- [Versão oficial](https://igorgomes.eti.br/escala-de-equipe/)
- Para testar localmente, execute `python3 -m http.server 8000` na raiz do repositório e abra `http://localhost:8000/escala-de-equipe/`.
- Os cálculos e a geração dos arquivos ocorrem no navegador. As licenças das dependências estão nesta pasta.
